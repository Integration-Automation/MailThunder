## U-20261001-01 · 2026-10-01 · Every workflow job has a timeout · #ci #tests

- **What**: every job that runs on a runner sets `timeout-minutes`, about three times its slowest recent run and at least 15 minutes. Without it a hung job runs for GitHub's default 360 minutes and holds the runner. Timeouts: `publish_stable.yml`: `test` 30, `publish` 15; `test_dev.yml`: `test` 30; `test_stable.yml`: `test` 30.
- **Tests**: `test/unit_test/test_workflow_actions.py` `test_every_job_has_a_timeout` fails for any job with `runs-on` and no `timeout-minutes`; the previous workflows fail it.
- **Files**: `.github/workflows/publish_stable.yml`, `.github/workflows/test_dev.yml`, `.github/workflows/test_stable.yml`, `test/unit_test/test_workflow_actions.py`.

## U-20261001-02 · 2026-10-01 · Executor and its helpers move to je_action_core · #migration #executor #L-6

- **What**: workspace L-6. MailThunder now builds on `je_action_core` (Integration-Automation/ActionCore), the executor core it shares with APITestka, LoadDensity and FileAutomation.
  - Now from the core, configured with MailThunder's settings:
    - `Executor` (subclassing `ActionExecutor`), with `SAFE_BUILTINS` re-exported here;
    - `PackageManager` (gate off);
    - `read_action_json` / `write_action_json`;
    - `get_dir_files_as_list`;
    - the socket server, with `_validate_payload` passed in as its check.
  - Unchanged: the `MT_*` commands, the deferred SMTP/IMAP calls, `action_list_from_mapping` (now the core's `ActionListRules.from_document`), the `auto_control` deprecation, the empty-list `{}`, every exception and message, `TCPServer` / `TCPServerHandler`, `start_mail_thunder_socket_server` and its deprecated alias.
- **Small differences, by design**:
  - the package manager's and JSON files' log lines use the core's wording;
  - a failed write of unserialisable data now leaves the file as it was (MailThunder already serialised first);
  - the magic `2` in `_validate_payload` is now `_MAX_ACTION_ELEMENTS`.
- **Dependency**:
  - `pyproject.toml` and `dev.toml` now depend on `je_action_core`; it was `[]` before. The README "Requirements" (three languages) and the Sphinx installation and index pages (Eng and Zh) say so.
  - It is not on PyPI yet, so `test_dev.yml`, `test_stable.yml` and `publish_stable.yml` install it from GitHub at a fixed commit.
  - `progress.md` #9 switches to PyPI; do not release `main` before that.
  - `progress.md` #8 now says the package gate is one setting away.
  - `architecture.md` §6 gains the ActionCore bullet, and its stale builtins text is corrected: LoadDensity and WebRunner use the same allowlist.
- **Result / numbers**: 112 passed (unchanged). ruff passes on the moved modules, zizmor reports informational findings only, and `sphinx -W` builds.
